🔄 FLUJO TÍPICO - Crear Nueva Asignación:
════════════════════════════════════════════════════════════════════════════════

  1. Admin accede a Panel Admin → Académico
  2. Selecciona "Nueva Asignación"
  3. Elige:
     - Profesor: Juan García (ID:5)
     - Materia: Matemáticas (ID:3)
     - Curso: 10-A (ID:1)
  4. Frontend envía:
     POST /api/admin/asignaciones
     {
       "profesorId": 5,
       "materiaId": 3,
       "cursoId": 1
     }
  5. Backend valida:
     ✓ Profesor existe
     ✓ Materia existe
     ✓ Curso existe
     ✓ No es duplicado
  6. Guarda en BD:
     INSERT INTO profesor_materia (profesor_id, materia_id, curso_id)
     VALUES (5, 3, 1);
  7. Responde:
     HTTP 200 OK
     { "id": 42, "profesor": {...}, "materia": {...}, "curso": {...} }
  8. Frontend actualiza tabla y muestra confirmación
